# Брось кубик — сайт магазина настольных игр

Учебный проект (курсовой проект, часть 3 — вёрстка). Многостраничный сайт на **HTML5, CSS3 (Flexbox/Grid) и чистом JavaScript** без библиотек и сборщиков.

## Страницы

| Файл | Страница |
|------|----------|
| `index.html` | Главная |
| `catalog.html` | Категории каталога |
| `listing.html` | Каталог с фильтрами и сортировкой |
| `product-*.html` | Карточки товаров (10 шт.) |
| `cart.html` | Корзина |
| `checkout.html` | Оформление заказа |
| `contacts.html` | Контакты и форма обратной связи |
| `about.html`, `delivery.html`, `events.html` | Информационные страницы и афиша |

## Структура

```
index.html … (страницы в корне)
css/style.css      — все стили (BEM)
js/main.js         — корзина (localStorage), шапка, уведомления
js/listing.js      — фильтрация и сортировка каталога
js/cart.js         — страница корзины, промокод
js/checkout.js     — оформление заказа
js/forms.js        — валидация форм
js/contacts.js     — форма обратной связи
js/data.js         — данные товаров для корзины (создаётся tools/build.py)
img/               — логотип и иллюстрации товаров (SVG)
tools/             — скрипты, из которых собираются HTML-страницы
```

## Запуск локально

Откройте `index.html` в браузере либо запустите локальный сервер:

```
python -m http.server 8000
```

и перейдите на http://localhost:8000/

## Публикация на GitHub Pages

1. Создайте на github.com новый **публичный** репозиторий, например `broskubik`.
2. Загрузите в него **содержимое этой папки** (файл `index.html` должен лежать в корне репозитория, а не во вложенной папке).
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/broskubik/`.

## Проверка в W3C Validator

Откройте https://validator.w3.org/#validate_by_uri и вставьте адрес каждой страницы, либо используйте вкладку «Validate by File Upload» и загрузите HTML-файлы.

## Как заменить изображения

Иллюстрации товаров лежат в `img/` (`wingspan.svg`, `carcassonne.svg` и т. д.). Чтобы использовать настоящие фотографии, положите файл с тем же именем и другим расширением (например, `img/wingspan.jpg`) и замените путь в `src` внутри `product-wingspan.html`, `listing.html`, `index.html`, `catalog.html` — либо измените `p['image']` в `tools/build.py` и выполните `python tools/build.py`.

## Примечания

- Формы обратной связи и заказа проверяются в браузере, но **никуда не отправляются** (на GitHub Pages нет серверной части). Для реальной отправки можно подключить сервис форм (например, Formspree).
- Цены, остатки, даты событий и отзывы — условные данные для демонстрации.
- Промокод для проверки корзины: `КУБИК10` (скидка 10 %).
